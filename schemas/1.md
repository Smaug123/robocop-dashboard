# Robocop Batch Metadata Schema

This document describes the metadata schema used by Robocop when creating OpenAI batch jobs. The dashboard reads this metadata to display review information.

## Schema Version

Current version: `1`

The `metadata_schema` field indicates the schema version. The dashboard will display a warning if it encounters an unrecognized version.

## Batch Identification

The dashboard identifies Robocop batches by checking:
- `metadata.description` equals `"robocop code review tool"`
- `metadata.metadata_schema` equals `"1"`

## Metadata Fields

All fields are strings stored in the OpenAI batch `metadata` object.

| Field | Required | Description |
|-------|----------|-------------|
| `description` | Yes | Always `"robocop code review tool"` |
| `metadata_schema` | Yes | Schema version, currently `"1"` |
| `source_commit` | Yes | Full SHA of the commit being reviewed (HEAD) |
| `target_commit` | Yes | Full SHA of the merge-base commit |
| `branch` | Yes | Branch name, or `"<no branch>"` if detached |
| `repo_name` | Yes | Repository name (e.g., `"robocop"`) |
| `model` | Yes | OpenAI model used (e.g., `"o3-2025-04-16"`) |
| `reasoning_effort` | Yes | Reasoning effort level, e.g. `"low"`, `"medium"`, `"high"` (others exist, as defined by OpenAI) |
| `remote_url` | No | Git remote URL (HTTPS or SSH format) |
| `pull_request_url` | No | Full URL to the pull request |
| `version` | No | Robocop tool version |

## Review Output Format

The batch output contains a JSON object with:

| Field | Type | Description |
|-------|------|-------------|
| `substantiveComments` | boolean | `true` if the review found issues worth noting |
| `summary` | string | GitHub-flavoured-Markdown-formatted summary of the review |
| `reasoning` | string | GH-flavoured-Markdown-formatted reasoning behind the review |

## Example Metadata

```json
{
  "description": "robocop code review tool",
  "metadata_schema": "1",
  "source_commit": "abc123def456...",
  "target_commit": "789xyz...",
  "branch": "feature/new-dashboard",
  "repo_name": "robocop",
  "model": "o3-2025-04-16",
  "reasoning_effort": "medium",
  "remote_url": "git@github.com:user/robocop.git",
  "pull_request_url": "https://github.com/user/robocop/pull/42",
  "version": "0.1.0"
}
```
